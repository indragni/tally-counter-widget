A tally counter with increment, decrement and reset.

Live tool and hosted embed: https://livetallycounter.com/

## Use it

Put `widget.js` on your site and add this to the HTML.

```html
<script type="module" src="./widget.js"></script>
<tally-counter-widget></tally-counter-widget>
```

The module registers the element. It has no dependencies or required setup.
Each instance keeps its state in memory until the page is closed or reloaded.

[Live demo](https://indragni.github.io/tally-counter-widget/) · [Hosted embed setup](https://livetallycounter.com/embed-on-your-site/)
